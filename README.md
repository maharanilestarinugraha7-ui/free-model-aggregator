# free-model-aggregator

One server, two APIs (OpenAI Chat Completions + Anthropic Messages), every answer a live free OpenRouter model with quality-ranked selection, rate-limit-aware failover and per-model cooldowns.

Run: `node main.ts --list` prints the catalog; `node main.ts` starts the server.

Built by an AI agent for make.fun's "The best live free-model aggregator" bounty, $500 in USDC.
